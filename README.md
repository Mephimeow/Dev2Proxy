# Dev2Proxy

Dev2Proxy — инструмент для быстрого подключения к удалённым сервисам через разные протоколы (SSH, RDP, VNC, FTP и др.).

## Возможности

- Автоматическое определение доступных сервисов на хосте
- Поддержка множества протоколов
- Логирование всех подключений
- Удобный выбор протокола через CLI

## Требования

### Python-зависимости

Все модули входят в стандартную библиотеку Python, дополнительных пакетов не требуется.

```
Python 3.8+
```

### Системные зависимости

Для корректной работы необходимы следующие утилиты в системе (Linux/Unix):

- `ssh`
- `sftp`
- `telnet`
- `lftp` (для FTP)
- `xfreerdp` (для RDP)
- `vncviewer` (для VNC)
- `xdg-open` (для открытия URL в браузере)

Установка на Ubuntu/Debian:

```bash
sudo apt update
sudo apt install openssh-client telnet lftp freerdp2-x11 tigervnc-viewer xdg-utils
```

## Запуск

1. Клонируйте репозиторий или скопируйте файлы.
2. Запустите главный скрипт:

```bash
python3 main.py
```

3. Введите IP-адрес сервера и выберите протокол для подключения.
