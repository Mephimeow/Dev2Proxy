# Сканер сетевых сервисов

Простой инструмент для обнаружения активных сетевых сервисов на заданных хостах.

## Файлы

- `main.py` — точка входа в программу  
- `connector.py` — модуль для установки соединений  
- `input_handler.py` — обработка пользовательского ввода  
- `service_detector.py` — определение типов сервисов  
- `services.txt` — список известных сервисов и портов  
- `plan.txt` — план разработки  
- `connections.log` — лог подключений (не отслеживается в Git)

## Зависимости

Проект использует стандартную библиотеку Python. Дополнительные зависимости не требуются.

## Запуск

```bash
python3 main.py
